Problemas de Integración entre Fuentes

Se intentó cruzar este dataset financiero (NITs de empresas grandes/medianas vigiladas, prefijo 800...) con una base de datos de actividad económica (CIIU) de una Cámara de Comercio regional.
El cruce por NIT arrojó 0% de coincidencias, evidenciando que ambas fuentes cubren universos empresariales distintos (Supersociedades vigila sociedades comerciales de mayor tamaño a nivel nacional, mientras que el registro de Cámara de Comercio consultado corresponde a comerciantes de una región específica distinta a Cundinamarca).
Se documenta como limitación y se buscará una fuente de clasificación sectorial de cobertura nacional en la siguiente etapa.


Trazabilidad de la Información

Los datos originales no fueron alterados en la fuente. Se conservó el archivo crudo descargado directamente vía API pública de datos.gov.co, y todo el proceso de transformación (filtrado, pivoteo, cálculo de variables derivadas) fue automatizado y documentado en Python (pandas) para garantizar reproducibilidad.
