4. Fuentes de Datos

Documentación de fuentes primarias, secundarias y terciarias por nivel de cobertura.

1. Fuente Secundaria (Nacional/Regional) - Supersociedades (SIREM)

Institución: Superintendencia de Sociedades

URL: datos.gov.co / SIREM

Periodo: 2018 - 2024 | Formato: CSV / XLSX

Registros Aprox.: > 45,000 estados financieros por año

Variables: NIT, Activos, Pasivos, Utilidad, CIIU, Ciudad.

Pertinencia: Confiabilidad oficial para balances reales.

2. Fuente Primaria (Regional) - Encuesta Directa Mipymes Sabana Centro

Responsable: Trabajo de campo / Formulario Digital

Tipo: Primaria (Encuesta / Sensores de captura web)

Periodo: 2026 | Formato: JSON / REST API

Registros Aprox.: 350 muestras

Variables: Causal de riesgo, acceso a crédito, uso de canal digital.

Pertinencia: Aporta variables cualitativas no presentes en estados financieros.

3. Fuente Terciaria (Global) - Banco Mundial / GEM Data

Institución: World Bank Open Data

URL: databank.worldbank.org

Cobertura: Global (120+ Países) | Formato: CSV API

Variables: Business Entry Rate, Insolvency Index, GDP growth.

Pertinencia: Marco de referencia internacional.
