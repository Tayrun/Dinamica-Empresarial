4. Recolección y Selección de Fuentes

Clasificación de Fuentes
Primarias:

Obtenidas directamente por ustedes, por ejemplo una encuesta personal:

  • Año de creación
  • Sector
  • Número de empleados
  • Tiempo de funcionamiento
  • Dificultades
  • Acceso a financiación
  • Estado actual del negocio
  • Factores percibidos para la supervivencia
Secundarias:

Datos ya recolectados por entidades u organizaciones como:

  • DANE
  • Confecámaras
  • Cámaras de Comercio
  • Datos Abiertos Colombia
  • Banco Mundial
  • OCDE
Terciarias:

Plataformas o fuentes que recopilan/integran datos de terceros.

Documentación Requerida para Cada Fuente
  • Nombre
  • Institución responsable
  • URL
  • Tipo de fuente
  • Cobertura geográfica
  • Periodo
  • Formato
  • Método de adquisición
  • Número aproximado de registros
  • Variables
  • Fecha de descarga
  • Restricciones de uso
  • Pertinencia / Confiabilidad / Actualidad / Cobertura
