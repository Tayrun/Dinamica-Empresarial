Tratamiento ETL con SSIS aplicado a los problemas de calidad detectados en la Etapa 2.

Introducción

Se implementó un proceso ETL (Extract, Transform, Load) con SQL Server Integration Services (SSIS) para tratar los problemas de calidad detectados en la Etapa 2. El paquete SSIS recibe el dataset consolidado, aplica las reglas de limpieza, validación y homologación definidas en las fases anteriores, y escribe el resultado en SQL Server separando los registros aceptados de los que requieren revisión. A continuación se presentan las iteraciones ejecutadas durante la puesta a punto del paquete.
